BRIDGE NIGHTHACK DEMO CARD

PITCH
When an API provider ships a breaking change, Bridge traces that contract change to
the exact customer call sites that will fail, generates a bounded deterministic patch,
opens a real draft pull request, and verifies the exact commit in GitHub Actions.
Provider and customer then review the evidence, comment, and approve in one live
migration room. Changelogs tell customers what changed. Coding agents can modify a
repository when prompted. Bridge connects the two and carries the migration from
contract change to verified handoff.

SCOPE
- AtlasPay is fictional. This proof covers one TypeScript repository, one guarded
  request-key rename, one draft PR, and human review. It is not arbitrary-provider,
  arbitrary-language, autonomous-merge, or production-onboarding proof.
